# ROOTS Dental Clinic Website

## Build
- Create a premium, responsive dental brand system using white, off-white, deep teal, blue, and restrained green accents.
- Add a sticky desktop header, accessible mobile menu, typographic ROOTS logo, shared footer, back-to-top control, and mobile Call/WhatsApp/Book actions.
- Build separate Home, About, Doctors, Services, Contact, and 17 service-detail routes.

## Home
- Add the provided headline, supporting copy, patient-care imagery, two appointment-focused calls to action, and subtle entrance motion.
- Build an autoplaying, touch-friendly featured-services carousel with arrows, indicators, images, and working links.
- Add Why Choose ROOTS, featured services, patient experience, appointment banner, and contact/location preview sections.

## Content Pages
- About: ROOTS Foundation and editable CEO, MD, and HOD profile placeholders.
- Doctors: clearly labeled editable profiles with specialty filtering and appointment actions; no invented credentials.
- Services: complete catalogue of all 17 requested treatments using structured content and relevant imagery.
- Service details: consistent overview, indications, process, benefits, FAQ accordion, breadcrumbs, and appointment CTA.
- Contact: validated appointment request form, clinic details, map, directions, call, email, and submission notice.

## Technical Details
- Store clinic, service, doctor, navigation, and contact content in reusable data modules.
- Use local optimized imagery, semantic design tokens, responsive layouts, keyboard-friendly controls, and reduced-motion support.
- Add unique metadata to every public page and dynamic service metadata, plus LocalBusiness structured data.
- Verify routes, carousel controls/autoplay, modal/form interactions, contact links, responsive desktop/mobile layouts, and page rendering.
