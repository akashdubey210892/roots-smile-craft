# ROOTS Dental Brilliance

Create a modern, premium, professional, responsive dental hospital website for **ROOTS DENTAL CLINIC**, located in Yelahanka, Bengaluru.

The website should look like a high-quality modern dental healthcare website suitable for a reputed dental clinic/hospital in India. The design should communicate **trust, hygiene, advanced technology, expertise, comfort, and compassionate patient care**.

Use modern UI/UX design principles, clean typography, generous white space, subtle animations, premium healthcare aesthetics, high-quality dental/doctor imagery, rounded cards, soft shadows, modern icons, and a professional color palette.

The website must be fully responsive and optimized for:

* Desktop
* Laptop
* Tablet
* Mobile

Use a clean and premium dental/medical visual identity. Prefer a combination of **white, off-white, deep blue/teal, and subtle green/blue accents**, while keeping the overall appearance elegant and trustworthy.

Use high-quality royalty-free/stock-style dental images wherever appropriate. Images should be relevant to the specific service rather than generic images.
